# AI PhD UI/UX Overhaul & Real-Time Streaming Plan

This document breaks down the massive UI/UX redesign and real-time streaming integration into small, manageable, and isolated tasks. 
**Golden Rule:** We will complete one task at a time, test it thoroughly, and only move to the next once it is 100% stable, ensuring the current working logic is NEVER broken.

## Phase 1: Backend Streaming Infrastructure (The Foundation)
*Goal: Upgrade the backend to send live updates and stream text tokens without breaking the core Map-Reduce logic.*

- [x] **Task 1.1: Create SSE Endpoint**
  - Create a new endpoint (e.g., `GET /stream-review`) using FastAPI `StreamingResponse` (Server-Sent Events).
  - Keep the old `/generate-review` intact as a fallback to ensure we don't break existing functionality.
- [x] **Task 1.2: Broadcast Node Statuses**
  - Modify `search_node` and `reader_node` to yield real-time JSON statuses (e.g., `{"status": "fetching", "progress": "5/20"}`).
- [x] **Task 1.3: Enable LLM Token Streaming**
  - Update `writer_node` to use `streaming=True`.
  - Yield actual text tokens as they are generated by the Gemini/OpenRouter model.
- [x] **Phase 1 Testing:** Run a local python script to hit `/stream-review` and verify that JSON statuses and text tokens arrive sequentially in real-time.

## Phase 2: Frontend Layout & Theming (Structure)
*Goal: Set up the visual skeleton and Dark Mode support without wiring up the complex backend data yet.*

- [x] **Task 2.1: Implement Dark/Light Mode**
  - Install and configure `next-themes`.
  - Set up a theme toggle button and base Tailwind `dark:` color palettes matching the Figma design.
- [x] **Task 2.2: Structural Grid Layout**
  - Restructure `page.tsx` into a CSS Grid: Top Navbar (fixed), Left Sidebar (fixed width), Right Main Content (flexible).
- [x] **Task 2.3: Top Navbar Migration**
  - Move the existing form inputs (Topic, Author, Institution, Citation Style) and the Generate button into the new Top Navbar design.
- [x] **Phase 2 Testing:** Visually verify the layout and ensure toggling Dark Mode changes the colors correctly.

## Phase 3: Multi-Agent Tracker Sidebar (Left Panel)
*Goal: Build the live tracking UI that reacts to backend events.*

- [x] **Task 3.1: Build Tracker UI Skeleton**
  - Create the vertical stepper UI for the 3 agents (Research Crawler, Data Engineer, Content Writer) with states: Queued, Live, Done.
- [x] **Task 3.2: Connect SSE to Sidebar**
  - Use JavaScript `EventSource` to listen to the backend.
  - Dynamically update the active step based on backend JSON status updates.
- [x] **Task 3.3: Render Retrieved Papers**
  - Build the UI card for loaded papers.
  - Dynamically populate this list when the backend emits paper metadata.
- [x] **Phase 3 Testing:** Trigger a generation and watch the sidebar progress through the steps and load papers accurately.

## Phase 4: Real-time Document Editor (Right Panel)
*Goal: Bring the text generation to life with real-time markdown rendering.*

- [x] **Task 4.1: Editor UI Design**
  - Design the mock formatting toolbar (Heading, Bold, Italic, etc.) as shown in the design.
  - Style the paper container to look like a document page.
- [x] **Task 4.2: Real-Time Markdown Rendering**
  - Append incoming text tokens from the SSE stream directly into the React Markdown component.
- [x] **Task 4.3: Counters and Visual Effects**
  - Add the live "Words" and "Characters" counter at the bottom right.
  - Add the glowing "AI is writing..." indicator at the bottom left while streaming is active.
- [x] **Phase 4 Testing:** Run the full pipeline. Ensure the text streams smoothly, counters update live, and the final document renders perfectly with correct citations.
